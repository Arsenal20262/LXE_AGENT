# 越南备货输入资产契约

本页记录 PR1 资产契约，以及 PR3–PR7 的现行生成和绑定口径。业务规则见[现行设计](design.md)、[PR6 映射缺项设计](../../superpowers/specs/2026-10-04-vietnam-partial-sku-mapping-design.md)和[聊天绑定设计](../../superpowers/specs/2026-10-04-vietnam-chat-sku-binding-design.md)；[PR3 设计](pr3-workbook-design.md)保留其当时的完整映射要求。

## 已注册的两个本地资产槽

| 槽位 | PR1 原用途 | 当前五表运行要求 |
| --- | --- | --- |
| `vietnam_replenishment_template` | 完整业务模板 | 不读取其 `current`；保留槽位仅为已有接口兼容 |
| `vietnam_sku_parameter_map` | 运营维护的 SKU 级业务参数 | 必须有受信且至少含一个有效 SKU 的 `current` |

两个槽位在 PR1 均标记为 `desktop` 管理，底层契约仍保留。业务人员现只在聊天中上传一张 `.xlsx` 映射表；明确要求绑定时只绑定，附表查询或生成越南备货时先绑定，成功后再生成。`lxeskill vietnam sku bind` 使用本条或符合紧邻确认条件的上一条附件真实绝对路径、受信存储校验及安全替换；没有新附件时生成流程读取已绑定 `current` 的私有快照。绑定失败不得改用旧版生成。工作台只展示 SKU 当前版、上一版和回滚，隐藏旧完整模板卡片，不再提供 SKU 上传按钮。PR3 的离线生成接口接收已复制的映射表文件路径和同一轮雅仓数据，不读取模板槽，也不自动绑定用户附件。业务人员无需上传完整模板；只绑定时不调用雅仓，也不要求映射表预先覆盖未来的雅仓 SKU。

## 旧完整模板校验与新内置骨架

`validate_template(path)` 是 PR1 留下的只读校验入口，供旧完整模板辅助接口和维护时审计使用；PR3 不把该模板当作生成输入。它检查以下五张必需表，允许旧模板另有辅助表：

1. `越南备货清单`
2. `雅仓库存`
3. `雅仓动销`
4. `数据更改`
5. `库存商品信息`

校验还检查主表及辅助表的关键表头，以及主表 `AV2:AY2` 对 `数据更改!A2:D2` 的公式引用。真实模板的历史 SKU 可以重复；本模块仅统计非空行，不把历史行直接作为本轮输出。

PR3 的 `resources/skeleton.xlsx` 由全新工作簿构造，只保留已审计的五表表头、样式、公式和四参数默认值，跟随 Python wheel 发布。它不含历史 SKU、成本、价格、图片、批注或超链接。最终文件只保留上述五表和本轮 `VN8806` 雅仓 SKU，不依赖用户电脑残留的旧模板资产。

## SKU 参数表读取

`load_sku_parameters(path)` 读取第一个工作表。必需表头是 `SKU`、`成本`、`跨境价`、`折扣价`、`热销标记`，可选表头是 `上架时间`；列顺序不限。至少需要一个非空、唯一的文本 SKU，去掉首尾空格后精确匹配。三项价格可分别留空；非空值必须是有限、非负且可精确写入 Excel 的数值，显式 `0` 与空白不同。热销标记可空，非空时只接受 `1` 或 `2`。重复或非法 SKU、输入格公式、非法数值或精度、损坏或不安全 XLSX 会报错。

空白参数保留为缺失，不借用相似 SKU 或历史模板的数值。PR6 允许本轮雅仓 SKU 没有映射行，或已有行但个别价格为空：该 SKU 仍进入五表，映射输入及其依赖结果留空，其他可计算结果保留。有映射行且热销标记为空时才默认 `2`；没有映射行时主表 `B` 热销、`G` 成本、`AE` 跨境价、`AJ` 折扣价、`AC` 备货天数、`H` 备货量和 `AF:AM` 财务结果均为空。仓库产品资料的 `创建时间` 已由业务确认是真实上架时间，按精确 SKU 读取。旧映射表中若显式填写 `上架时间`，仅接受有效的 ISO 日期或日期时间，并与仓库产品时间核对，不用它覆盖商品资料。

PR2 的 `prepare_operator_sku_map(template_path, ...)` 与 `resolve_sku_parameters()` 仍提供历史模板参考能力，但当前五表生成不调用它们，也不从模板历史兜底。聊天上传表须保留五个必需表头；每行价格与热销值可空，旧版 `上架时间` 列可以保留以便兼容读取。没有受信 current、表内无有效 SKU、雅仓必要来源缺失及重算错误仍会使生成失败，不能当作允许留空的映射缺项。

真实九表模板、运营映射表、价格与成本数据均保存在本机受控资产或运行产物中，不进入 Git 或安装包；只有无历史业务数据的骨架资源随应用发布。
