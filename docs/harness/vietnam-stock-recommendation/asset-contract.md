# 越南备货输入资产契约

本模块只定义资产身份与只读校验。业务规则以[最终设计](design.md)为准；雅仓数据合并、运营回填、Desktop 绑定和五表生成由后续模块实现。

## 两个本地资产槽

| 槽位 | 用途 | 运行时要求 |
| --- | --- | --- |
| `vietnam_replenishment_template` | 完整业务模板 | 必须有有效的 `current` |
| `vietnam_sku_parameter_map` | 运营维护的 SKU 级业务参数 | 可选；缺失时仍可使用模板历史值和明确的业务默认值 |

两者均标记为 `desktop` 管理。现有命令上传入口不能更新它们；后续 Desktop 绑定入口负责候选文件校验、哈希与安全替换。当前模块只允许通过 `current_asset(slot_id)` 读取已绑定的当前版，不会自动绑定用户附件。

## 完整模板校验

`validate_template(path)` 只读检查工作簿。模板必须包含以下五张表，允许输入模板另有辅助表：

1. `越南备货清单`
2. `雅仓库存`
3. `雅仓动销`
4. `数据更改`
5. `库存商品信息`

校验还检查主表及辅助表的关键表头，以及主表 `AV2:AY2` 对 `数据更改!A2:D2` 的公式引用。真实模板的历史 SKU 可以重复；本模块仅统计非空行，不把历史行直接作为本轮输出。最终文件只保留上述五表和本轮 `VN8806` 雅仓 SKU。

## SKU 参数表读取

`load_sku_parameters(path)` 读取第一个工作表。必需表头是 `SKU`、`成本`、`跨境价`、`折扣价`、`热销标记`，可选表头是 `上架时间`；列顺序不限。SKU 必须是文本，去掉首尾空格后精确匹配，重复 SKU 会报错。成本与价格必须是有限非负数；显式 `0` 与空白不同。热销标记只接受 `1` 或 `2`。输入格中的公式不算运营显式值，会报错。

空白参数保留为缺失，不借用相似 SKU 的数值。若运营显式填写 `上架时间`，仅接受有效的 ISO 日期或日期时间；雅仓商品的 `创建时间` 不自动当作上架时间。参数优先级是：运营显式值、模板同 SKU 的无冲突历史值、已确认的业务默认值（热销标记为 `2`），最后才是缺失。

供运营上传的映射表以后只从本轮越南 SKU 和雅仓三类导出无法提供的 SKU 级字段提取。历史模板值可以作为核对依据；缺失或冲突必须标出，不能直接升级成运营显式填写值。这项提取和回填合并属于下一模块。

真实模板、运营映射表、价格与成本数据均保存在本机受控资产或运行产物中，不进入 Git 或安装包。
