# 越南备货：本轮雅仓数据与运营 SKU 表

本页记录 PR2 雅仓数据合并和运营表辅助接口，并说明 PR6 的现行五表运行口径及 PR7 的聊天绑定入口；详细条件公式见 [PR6 映射缺项设计](../../superpowers/specs/2026-10-04-vietnam-partial-sku-mapping-design.md)。PR2 的历史模板读取接口仍在代码中，但当前生成不调用它，也不依赖已绑定模板。业务总目标见[现行设计](design.md)；[PR3 设计](pr3-workbook-design.md)保留其当时的完整映射要求。

## 本轮数据范围

`export_vietnam_sources()` 复用现有 `services.yacang.workflow.run`，一次请求 `VN8806` 库存动销、`VN8806` 当前库存列表和全局仓库产品资料。仓库产品资料由雅仓原流程全局导出，读取时按本轮越南 SKU 精确筛选。请求不带库存动销的“创建日期”筛选，以免漏掉旧 SKU。

三份文件必须全部成功且身份正确。PR2 辅助运营核对表以越南库存动销与当前库存列表的**并集**为 SKU 集合；只在其中一份出现的 SKU 仍进入该辅助表，并标出缺少的实时来源。当前五表生成则要求每个本轮 SKU 都有必要的动销、库存和商品资料，缺项会失败。两份都为空时失败。空白、非文本或重复 SKU，以及保留行中的公式，都不能作为可靠输入。全局商品资料的其他 SKU 不进入本轮结果。

五表计算使用的“总在途”以当前库存列表的 `在途数量` 为准；动销的 `在途` 只做数值差异诊断，不补齐库存列表的空值。商品资料的 `创建时间` 已由业务确认是真实上架时间。PR2 仅保留该原始字段；PR3 按精确 SKU 校验并规范成 `YYYY-MM-DD HH:MM` 文本，缺失或冲突时停止生成。

## 运营上传表

PR2 的 `prepare_operator_sku_map(template_path, output_path, current_map_path=None)` 仍是依赖本地完整模板的**辅助接口**：它先校验模板和已有参数表，再取得本轮雅仓数据，最后生成一个新 XLSX。调用方已经取得同一轮数据时可传 `sources=`，避免再次导出。目标路径若已有文件会报错，不覆盖现有运营表。当前五表入口直接读取聊天绑定的受信映射表快照和应用内置骨架，不调用此辅助接口，也不要求用户上传完整模板。

第一张 `SKU参数映射` 表可由 PR1 的 `load_sku_parameters()` 直接读取。PR2 辅助输出的列为 `SKU`、`成本`、`跨境价`、`折扣价`、`热销标记`、`上架时间`；当前上传仍要求前五个表头，`上架时间` 是旧版兼容列。运营只需在聊天中上传一张 `.xlsx`；只要求绑定时只绑定，附表查询或生成越南备货时先绑定再生成。表内必须至少有一个有效 SKU，但不必覆盖本轮雅仓全部 SKU。三项价格可分别为空，已有映射行的空热销默认 `2`；上架时间来自仓库产品，无需运营填写。可编辑值仅从已有运营显式参数表带入；无显式值则留空，显式零仍为零。

PR2 辅助输出的第二张 `核对参考` 表展示同 SKU 的模板历史参数、历史冲突或无效原因，以及缺动销、缺库存、缺商品、缺总在途、在途不一致标记。历史值绝不写入第一张表的可编辑单元格。该参考页不属于 PR3 生产输入，也不能让历史值自动成为已确认价格。高精度价格按文本保存以保留精确值，PR1 读取时仍按数值校验。

PR2 的 `resolve_sku_parameters()` 保留旧模板历史分析能力，但当前生成不用其模板历史兜底。五表以本轮雅仓 SKU 为行集合，按精确 SKU 左连接运营表；额外映射 SKU 不进入结果。没有映射行时，该 SKU 仍保留雅仓字段和独立计算，主表 `B/G/AE/AJ`、`H/AC` 与 `AF:AM` 留空。有映射行但个别价格为空时，备货结果继续计算，只留空依赖该价格的财务列。PR2 参考页中的历史值不会悄悄变成运营显式输入。

## 调用边界与错误

`vietnam-stock-recommendation` Skill 遇到附表查询或生成越南备货时，先将当前消息恰好只有一个附件且它是 `.xlsx` 的文件，或符合紧邻确认/继续处理条件的上一条唯一未绑定 `.xlsx`，交给 `lxeskill vietnam sku bind --source-path`；绑定成功后才运行现有无参数生成命令，失败时停止且不沿用旧 `current`。没有待处理新附件，或紧邻附件已成功绑定时才沿用受信 `current`；多附件先确认，单独上传但用途不明先询问，非 `.xlsx` 不绑定也不改用旧版生成。工作台可查看当前版、上一版并回滚，但不再上传。独立绑定命令校验文件路径与内容，附件是否来自本轮聊天由 Skill 选择，CLI 无法单独证明。没有受信 current、空表、重复或非法 SKU、非法价格或精度、损坏或不安全 XLSX，以及四参数配置不完整或非法，均在雅仓导出前失败。雅仓三类导出及必要字段缺失、骨架损坏、Office Kit 重算或结果校验失败也继续报错。真实九表模板、雅仓导出、价格和运营表保持在本地受控目录，不提交 Git，也不随安装包分发；安装包仅发布从全新工作簿构造、无历史数据的五表骨架。开发验证使用合成 XLSX 和已有雅仓本地模拟测试，没有调用生产雅仓；真实雅仓导出及最终五表仍需现场联调。
