# 统计上传改用设备鉴权

桌面 Agent 的统计上传与独立飞书网关逐步迁移到 `WireGuard 来源 → 有效设备 → 上传`，不依赖 Skill 范围或桌面业务 Token。桌面整体凭据生命周期仍保留，管理员、设备接入、模型和网页会话不变。

桌面运行时复用公司直连 HTTP 通信，携带 `X-LXE-Client: cli`；不发送 Authorization/Cookie、不走代理、不跟随重定向。上传启用只取决于有效接入配置，旧 Token 失效不会阻止上传。

失败后本地记录和公司地址游标保留，恢复后重发未确认批次。只有完整有效 ACK 才推进游标；超过 1 MiB 的 ACK 明确报错，不当作成功。首次同步仍保留原有一年历史窗口，已经待上传的记录不因跨过一年而跳过。服务端去重确保 ACK 丢失后重发不增加重复统计。

备用服务器配置、密钥、环境注入与重试路径已删除。旧配置文件允许读取，但会剔除废弃字段。不会合并旧备用地址游标，也不重建机器实例 ID。

HTTP 409 归属冲突暂停该运行时上传，保留真实诊断；管理员核实修复归属后重启运行时。401/403 和网络失败保留数据，后续周期重试。服务端对来源设备的检查不会被正文 machine_id 或转发头替代。

服务器必须先部署兼容版本。已知未验证的历史统计实例需先核实归属；不要用新建 machine_id 绕过。详细操作见服务器仓库 `docs/native-statistics-upload.md`。独立飞书网关的本机 MCP 转发、配置迁移和未来发布步骤见该仓库 `docs/company-device-auth.md`。

本轮不生成桌面安装包，不发布或重启 Mac mini 飞书网关，不发送飞书消息，不向生产写入模拟统计。
