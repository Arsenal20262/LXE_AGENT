# 备货类型改名

Skill 类型统一为 `replenishment`，中文“备货”、英文“Replenishment”。9 个备货 Skill 的名称、目录和 CLI `lxeskill replenish …` 命令不变；没有修改业务权限、设备身份或网关凭据。

桌面只在读取已校验的历史权限缓存时把 `amazon_replenish` 转成新名称，保留绑定、版本和验证时间，不把缓存当成新验证结果。在线权限仍来自服务器，不会根据旧名称追加新授权。服务器必须配套迁移当前模板并递增发布版本。

本地 SQLite 统计在分组前转换旧名称，同一技能和任务重新去重；云端统计使用相同规则。界面统一显示“备货”。原始执行明细、历史记录和上传载荷保留原值，上传确认和进度不变，不需要清库或重新上传。该统计转换不参与权限判断。

## 同步升级与回退

本次只交付本地提交和测试，没有部署或生成安装包。后续安排维护窗口，暂停受影响客户端与模板编辑，备份后先更新服务器并执行 `0037_replenishment_type` 迁移，再更新客户端。核对权限查询、9 个技能加载、历史混合统计和离线补传。不要在新旧客户端混用期间承诺备货可用。

回退须协调服务器和客户端版本。服务器反向迁移追加更高版本的旧名称快照，不覆盖历史。回退客户端后重新查询权限；若旧客户端不能读取新格式缓存，仅清除权限快照后验证，不能清除设备身份、业务数据、统计文件或上传进度。完整服务器步骤见服务器仓库 `docs/replenishment-type-rename.md`。
