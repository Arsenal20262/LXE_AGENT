# 马帮 TMS 数据导出

## 范围

- 用户明确提到马帮 TMS 或 TMS 时使用。仅说“马帮”且上下文无法确定系统时，先用已有问答工具区分马帮 ERP 与马帮 TMS；不混用两套账号。
- 仅提 Shopee/虾皮不足以唯一确定马帮 TMS；若上下文不能确定取数系统，先询问用户，不根据销售平台名称猜 ERP。
- 默认导出当前账号可见的全部仓库、正常商品、全部库存状态。库存、销量、商品资料使用同一次商品导出，不分别执行；不能把当前账号范围说成固定菲律宾。
- 指定仓库、日期、历史库存、逐日销量、独立上架报表或自选字段均超出本命令能力，先说明限制并确认是否接受默认范围。此处描述的是本 Skill/CLI 当前不提供这些筛选能力，不代表马帮 TMS 的其他 API 完全不支持。取消或跳过时停止。

## 数据来源、接口与字段

- 马帮 TMS 是本 Skill 的取数系统；当前导出的商品、库存和销量记录属于 Shopee 业务。数据来自马帮 TMS，不是 Shopee 官方接口。Shopee 业务归属不表示接口能按平台筛选，也不能据 SKU 或商品名称推断平台归属。
- `POST /login` 用于账号认证，不导出业务数据。
- `POST /findMyStockwarehouseList` 分页读取当前配置账号可见的商品/仓库记录；`POST /exportStockwarehouse` 按该批记录 ID 和固定字段请求原始报表。接口返回下载信息，CLI 随后下载并校验各批文件，再合并为一份 XLS/XLSX 交付；不要把下载信息本身当成最终文件，也不要绕过 CLI 直接请求接口。
- 已核实的报表字段包括：`库存SKU`（商品库存记录的 SKU 编码）、`仓库`、`库存量`、`可用库存`、`在途量`、`7天销量`、`15天销量`、`30天销量`、`成本价`、`采购价`和`入库时间`。库存各列按 ERP 原始字段展示，不推导字段间公式；销量列分别对应其表头标注的时间窗口，不是逐日明细。`入库时间`不等于已确认的首次入库或商品上架时间。
- 当前表头合同未保证每次都包含“商品名称”列，不要承诺一定导出该字段。`sale5` 是请求字段；只有源表明确返回相应列名时才按该列名说明，不得自行推断其时间窗口。

## 执行与交付

通过 `exec` 调用，不传凭据，不自行拼 API，也不先预览：

```text
lxeskill mabang-tms products export
```

- 账号密码在桌面“马帮 TMS”配置。每次任务登录一次，各批复用内存登录态。命令运行中等待同一执行，不重启导出。
- 只以最后一条 `type="result"` 的 `ok / data / error / files` 为结果。完成需脚本确认所有接口记录及各批文件通过校验；一批成功、页数或文件存在不能代表全量完成。
- 独立导出或数据准备任务，把 terminal `files` 交给 `send_files` 一次，已发送的不重复发送。发送成功才称已交付，发送失败只重试发送。
- 交付的是生成的合并 Excel，平台原始分批文件本地保留。合并只追加行，不按 SKU 去重、累加销量、删改负库存或零价格。同 SKU 多行可能重复携带销量，不能直接相加。
- 按结果分别说明接口总记录数、已读取／已导出唯一 ID 数、完成批次数、导出行数、不同 SKU 数和实际仓库；零记录且无文件时明确没有数据，不声称已发送 Excel。
- 完成指本轮接口筛选范围内完成。结果中的仓库仅代表本轮数据涉及的仓库，不能据此断言账号只拥有这些仓库；与网页记录数不一致时说明尚需核对相同筛选范围，不声称已覆盖网页的全部记录。
- `ok=false` 且 `data.status=partial_success` 时，可发送 `files` 中的部分文件，同时说明实际错误、已完成范围和剩余记录，不能称全量完成。失败不自动重跑、不刷新马帮 ERP 登录；用户明确重试才执行新任务。
- 错误转述实际脱敏诊断，不读取或展示账号密码、Token、签名下载 URL。不进行备货计算。
